# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Reporting a vulnerability

Email hello@indianopinion.org with "tldr-block security" in the subject. Please include the version, a description, and steps to reproduce. Do not open a public issue.

We reply within 5 working days, agree a fix and a disclosure date with you, and credit you in the release notes unless you prefer otherwise.

Things we especially want to hear about: a way to show unapproved text to readers, to approve without the approve capability, to write the plugin's post meta through the REST API, or to read the API key.
